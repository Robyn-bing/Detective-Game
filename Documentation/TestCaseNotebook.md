# Test 场景：案件笔记与暂停菜单

仅 Test 场景的 DialogueController 启用 `Use Case Notebook`。其他场景仍使用原来的调查菜单入口。

- Tab 打开／关闭案件笔记；左上角竖排「证言／物证」标签支持鼠标切换。
- 保留现有证言关系图、解锁内容、物证列表、描述、回溯预览、空格播放暂停、时间轴和拖拽推断。
- 重新打开记住上次页面和物品，切页保留当前物品的回溯时间点。
- 普通对话中可打开笔记，关闭后恢复原对话；托管剧情和回溯期间沿用原来的输入限制。
- 在没有面板的探索状态长按 Esc 0.45 秒，底部显示填充进度，完成后打开暂停轮盘。
- 松开不足时长的 Esc 会取消进度；关闭面板后继续按住不会再次打开菜单。
- 暂停轮盘复用原轮盘的背景模糊、展开／收起、分项延迟和悬停动画，并增加点击按压反馈。
- 五项为「存档、快速存档、提示、设置、返回标题」，点击仅提示功能正在开发，不保存、不切换场景。
- 菜单打开后冻结游戏时间，Esc 关闭动画结束后恢复先前时间倍率和输入。

长按阈值可在 Test 场景 DialogueController 的 `Pause Hold Duration` 调整。

## 回归验证

进入 Test 的 Play Mode，执行菜单：
`Tools > Detective Game > Run Case Notebook Smoke Tests (Play Mode)`。

测试注入临时键盘输入，验证面板切换、长短按边界、暂停时间恢复、普通对话返回，以及现有物证预览与推断。测试会临时解锁书本物证，退出 Play Mode 后恢复原场景数据。

结果及界面截图写入 `Temp/NotebookQA/`。测试不实现或调用真实存档、读档和返回标题功能。
